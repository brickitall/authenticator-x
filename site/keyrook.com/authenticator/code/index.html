Is it safe to paste a key here?

This page cannot send it. Its Content Security Policy forbids it to load or send anything, and to run any script but its own — rules your browser enforces, whatever anyone serving the page might want. It loads nothing from anywhere else, and keeps working with the network off once it has opened.

Still, a web page is for checking a key or getting one code in a pinch, not for keeping keys. For the accounts you use, an authenticator app keeps them encrypted and ready.
